# User Guide: Public Filter System (v2.0)

## What's New?

LivePick now lets you **share filters with the community** and **import others' filters as your own editable copy**.

No more recreating the same filters! Find tested, proven filters and customize them for your needs.

## 5-Minute Overview

### Share Your Filter (Make it Public)

1. Go to **Filters** section
2. Find the filter you want to share
3. Click the **Lock icon** (next to the notification bell)
4. Icon changes to **Share** → Filter is now public ✅

**Result:** Other users can now find your filter in the **Community Library**

### Import a Filter (From Community)

1. Tap **Library** in the bottom menu (or go to `/dashboard/library`)
2. Browse filters shared by other users
3. Click **Import Filter** button
4. Filter appears in your library with **(v2.0)** label
5. Edit it as much as you want!

**Result:** You now have your own editable copy. Original filter is unchanged.

### Edit Your Imported Filter

- All imported filters are **fully editable**
- Change conditions, name, notifications
- Your copy is independent (original isn't affected)
- Stats are reset (0 triggers, no history)

## Key Concepts Explained

### What is v2.0?

- **v1.0** = Your original filter
- **v2.0** = Someone's imported copy
- **v3.0** = Someone imported the v2.0 and shared it, then another imported it

Each version is **completely independent**. Changes to v2.0 don't affect v1.0.

### What Happens When I Import?

✅ Your copy has the same conditions as original  
✅ Your copy starts with 0 triggers (fresh stats)  
✅ Your copy is private by default (only you see it)  
✅ You can edit, rename, customize it  
✅ You can make YOUR copy public too!  
❌ Original filter is never changed  
❌ Original filter doesn't know about your copy  

### Can I Edit Someone Else's Filter?

**No**, but you can **import it and edit your copy**.

```
Trying to edit filter in Library?
→ "This filter cannot be edited"
→ "This is a read-only base filter"
→ "Import it to create your own editable version"

Solution: Click "Import Filter" to get your editable v2.0
```

### What If I Already Imported Something?

You can't import the same filter twice:

```
Trying to import again?
→ Error: "You already have this filter imported"
→ "Filter 'Big Scorers v2.0' is already in your library"
→ Just use your existing copy!
```

Edit your existing copy or delete it and re-import fresh.

## Tips & Tricks

### 💡 Pro Tips

1. **Check success rate** - Higher % = more reliable
2. **Sort by triggers** - More triggers = well-tested
3. **Read description** - Understand what it does
4. **Test first** - Import and test before enabling notifications
5. **Combine ideas** - Take best conditions from multiple filters
6. **Share improvements** - If you improve an imported filter, make your version public

### ⚠️ Common Mistakes

- ❌ Enabling notifications on untested filter
  - ✅ Import, test a few matches, then enable notifications

- ❌ Modifying someone's filter in library
  - ✅ Import it first, then edit your copy

- ❌ Forgetting to disable notifications
  - ✅ Check notification settings before making filter public

### 🎯 Best Practices

1. **Version Your Improvements**
   - Import filter → test → improve → make public
   - Result: Creates new v2.0 or v3.0 with your improvements

2. **Document Your Filters**
   - Add description: "Corners over 10 in EPL & La Liga"
   - Helps others understand conditions

3. **Test Before Sharing**
   - Don't share untested filters
   - Community benefits from reliable filters

4. **Give Credit**
   - System automatically shows "Forked from: raiz"
   - No manual credit needed

## FAQ

**Q: Will my original filter change if someone modifies theirs?**
A: No! Each import is completely independent. You can't change others, they can't change you.

**Q: Can I see who imported my filter?**
A: Not yet, but it's planned for future versions.

**Q: What if the original filter gets updated?**
A: Your imported copy stays the same. It's independent. If you want the update, delete your copy and re-import.

**Q: Can I make my imported filter public?**
A: Yes! Click the Share button (Lock icon) and your v2.0 becomes public. Others can import it too!

**Q: What happens to my import if I delete the original?**
A: Your import remains. Deleting the original doesn't affect your copy.

**Q: Can I edit my shared filter after others import it?**
A: Yes, but only you have v1.0. Their copies (v2.0, v3.0) stay independent.

**Q: Is there a limit to how many filters I can import?**
A: No limit! Import as many as you want.

**Q: Can I export/backup my filters?**
A: Feature coming soon. For now, keep good filters in your library and maybe make them public.
